Skill UX 70s

Skill desain UX untuk Codex yang membantu kamu merancang alur pengguna, layout responsif dengan shadcn/ui, dan kondisi layar untuk Figma atau implementasi kode.

Buka repositori GitHub

Instal di proyek Codex

Jalankan perintah ini dari folder proyek dengan Node.js 22.20 atau lebih baru.

npx skills add ihsan70s/skill-ux-70s --skill skill-ux-70s --agent codex

Buka proyek di Codex dan panggil $skill-ux-70s. Petunjuk untuk agen lain ada di README.

Contoh prompt

Gunakan $skill-ux-70s untuk merancang halaman daftar produk dengan shadcn/ui. Sertakan alur menambah, mengedit, dan menghapus produk, termasuk konfirmasi dan kondisi saat terjadi error.
